# Hosted WebKit presentation and fast-input regressions

Run [38175076210](https://github.com/milocosmopolitan/pxoracle/actions/runs/38175076210), commit `4f2d167`, passed the native keyboard globe test on hosted Ubuntu WebKit. Enter generated click events and incremented public revisions. East, zoom-out and west produced distinct settled images. After the bounded presentation follow-up, the raw WebGL draw count remained 372 across the 500 ms reduced-motion idle check. [Raw public diagnostics](webkit-keyboard-hosted.json) contain no birth records, coordinates or search text.

The previous run accepted zoom revision 3 and submitted its GL draws, but the compositor retained the old image. A bounded follow-up presentation draw resolved that observed failure; it adds no continuous reduced-motion rendering loop. Production scene tests separately verify the 1.12 distance ratio, unchanged globe/camera orientation and projection, and exact idempotence when the same adjustment revision is rendered again.

The new run had a separate HTML fallback failure: its synthetic country change was followed by input filling about 58 ms later, and the final search field was empty. Both atlas requests returned HTTP 200 in approximately 9–12 ms. The country-reset passive effect could therefore erase newly entered text after the country changed; this was not an atlas timeout. The production fix moves that narrow reset to a layout effect before the newly selected country becomes interactive. The fallback regression types immediately, with no sleep or readiness delay, and asserts the exact input remains present both before and after results appear.

At this evidence snapshot, the hosted suite had 29 passed, 2 explicitly unsupported skips and 1 fast-input failure. The hosted keyboard fix is verified; final hosted verification of the search-reset fix remains pending. Local macOS WebKit results are separate and do not claim hosted Linux or physical mobile coverage.

The repaired static export passed six local macOS WebKit checks in 13.4 seconds: three repeats of injected asset retry plus immediate fallback search, and three repeats of country/candidate/timezone invalidation with manual entry. The fallback test asserts the exact synthetic input survives both before and after result rendering, without a delay between country selection and typing. This local result does not replace the pending hosted rerun.
